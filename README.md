# Decidim::KpiManager

KPI management component for Decidim.

## Usage

KpiManager will be available as a Component for a Participatory
Space.

## Installation

Add this line to your application's Gemfile:

```ruby
gem "decidim-kpi_manager"
```

And then execute:

```bash
bundle
```
